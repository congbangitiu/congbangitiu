## About

**E-commerce delivery**<br />
Build production interfaces for product, cart, checkout, account and landing pages. Integrate Magento APIs and validate checkout flows with Vitest.

**Reliability and growth**<br />

Build applications with Node.js, Express, MongoDB, Socket.IO and Stripe. Use AI tools to debug, write tests and refactor faster.
